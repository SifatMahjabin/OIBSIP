# Predicting House Prices with Linear Regression

**Track:** Data Analytics — OIBSIP
**Deliverable folder:** `OIBSIP/DataAnalytics-L2-HousePrice/`

## Objective
Build and evaluate a linear regression model that predicts house prices based on features such as area, location, number of rooms, and age. Develop end-to-end skills from data cleaning through to model interpretation.
## Tech Stack
Python, pandas, scikit-learn, matplotlib, seaborn, Jupyter Notebook


## What's in this folder
- `HousePricing(L-2,T-1).py` — full pipeline: data loading, EDA, analysis, and charts, with inline comments explaining each decision (as required by the checklist's "written observation" items).
- `plots` (created on run) — all chart images generated by the script.

## Dataset used
This uses the real **Ames Housing** dataset (`data/AmesHousing.csv`, 2,930 rows / 82 columns). To keep the model interpretable, only a focused feature set is used — Area, Rooms, Quality, Age, and top-10 Neighborhood (one-hot encoded, rest grouped as "Other") — rather than all 82 raw columns. Real result: R² = 0.79 on the held-out test set.
