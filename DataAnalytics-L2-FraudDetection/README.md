# Fraud Detection

**Track:** Data Analytics — OIBSIP
**Deliverable folder:** `OIBSIP/DataAnalytics-L2-FraudDetection/`

## Objective
Build a machine learning pipeline to detect fraudulent financial transactions from a heavily imbalanced dataset, addressing class imbalance as a core challenge.
## Tech Stack
Python, pandas, scikit-learn, imbalanced-learn (SMOTE), matplotlib, seaborn, Jupyter Notebook


## What's in this folder
- `FraudDetection(L-2,T-3).py` — full pipeline: data loading, EDA, analysis, and
  charts, with inline comments explaining each decision (as required by the checklist's "written observation" items).
- `plots` (created on run) — all chart images generated by the script.

## Dataset used
This uses the real **Creditcard_data.csv** you provided — but note it's a SMALL SUBSET (772 rows, only 9 fraud cases = 1.17%) of the full Kaggle Credit Card Fraud dataset (which has 284,807 rows / 492 fraud). With only 9 fraud examples, the test split ends up with just 1-2 fraud cases.
