# Wine Quality Prediction

**Track:** Data Analytics — OIBSIP
**Deliverable folder:** `OIBSIP/DataAnalytics-L2-WineQuality/`

## Objective
Train and compare multiple classification models to predict the quality score of wine (typically a scale of 3-8) based on its physicochemical properties such as acidity, density, and alcohol content.
## Tech Stack
Python, pandas, numpy, sckit-learn (Random Forest, SGD,SVC). seaborn,matplotlib,Jupyter Notebook

## What's in this folder
- `WineQuality.py` — full pipeline: data loading, EDA, analysis, and
  charts, with inline comments explaining each decision (as required by the
  checklist's "markdown / written observation" items).
- `plots/` (created on run) — all chart images generated by the script.

## Dataset used
This uses the real Kaggle **WineQT** dataset (`data/WineQT.csv`, 1,143 rows). Column names match the task spec exactly (fixed acidity, volatile acidity, ... quality). Real class imbalance shows up clearly: quality 5/6 dominate (945 of 1,143 wines), while the "low" tier (quality 3-4) has only 39 examples, so SVC and SGD fail to learn it at all (0% recall) while Random Forest does somewhat better — a genuine, instructive result for the class-imbalance discussion the task asks for.
