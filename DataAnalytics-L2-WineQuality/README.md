## Dataset used
This uses the real Kaggle **WineQT** dataset (`data/WineQT.csv`, 1,143 rows). Column names match the task spec exactly (fixed acidity, volatile acidity, ... quality). Real class imbalance shows up clearly: quality 5/6 dominate (945 of 1,143 wines), while the "low" tier (quality 3-4) has only 39 examples, so SVC and SGD fail to learn it at all (0% recall) while Random Forest does somewhat better — a genuine, instructive result for the class-imbalance discussion the task asks for.
