# EDA on Retail Sales Data

**Track:** Data Analytics — OIBSIP
**Deliverable folder:** `OIBSIP/DataAnalytics-L1-EDARetailSales/`

## Objective
 Perform a thorough Exploratory Data Analysis on a retail sales dataset to uncover patterns, customer behaviour trends, and actionable business insights.
## Tech Stack
Python, pandas, matplotlib, seaborn, Jupyter Notebook

## What's in this folder
- `EDA on retail sales data(L-1,T-1).py` — full pipeline: data loading, EDA, analysis, and charts, with inline comments explaining each decision (as required by the checklist's " written observation" items).
- `plots` (created on run) — all chart images generated by the script.

## Dataset used
This uses the real Kaggle **Sample Superstore** dataset (`data/SampleSuperstore.csv`). Note: this particular upload has no Order Date or customer demographic columns, so the time-series and demographics checklist items are adapted to use Segment/Region/State breakdowns instead — this is called out in the script's comments. If you want true date-based trends, swap in the fuller *superstore-dataset-final* Kaggle upload, which includes an Order Date column.
