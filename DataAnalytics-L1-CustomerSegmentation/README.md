## Objective
Apply clustering algorithms to segment an e-commerce company's customer base into distinct groups based on purchasing behaviour, enabling targeted marketing strategies.
## Tech Stack
Python, pandas, scikit-learn (KMeans), matplotlib, seaborn, Jupyter Notebook

## What's in this folder
- `Customer_Segmentation(L-1,T-2).py` — full pipeline: data loading, EDA, analysis, and charts, with inline comments explaining each decision (as required by the checklist's " written observation" items).
- `plots` (created on run) — all chart images generated by the script.

## Dataset used
This uses the real UCI/Kaggle **Online Retail II** dataset (`data/online_retail_II.csv`, ~1M invoice-line rows). The script filters out cancellations (invoices starting with "C"), non-positive quantities, and rows missing a Customer ID before building RFM features — see the script's comments for the exact row counts removed.
