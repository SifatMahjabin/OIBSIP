# Unveiling the Android App Market (Google Play Store Analysis)

**Track:** Data Analytics — OIBSIP
**Deliverable folder:** `OIBSIP/DataAnalytics-L2-GooglePlayStore/`

## Objective
Perform a comprehensive data analysis of the Google Play Store ecosystem — cleaning messy real-world data, exploring app categories, analysing ratings and pricing trends, and conducting sentiment analysis on user reviews.
## Tech Stack 
Python, pandas, numpy, matplotlib, seaborn, TextBlob or VADER, Jupyter Notebook

## What's in this folder
- `googleplaystore(L-2,T-4).py` — full pipeline: data loading, EDA, analysis, and charts, with inline comments explaining each decision (as required by the
  checklist's "written observation" items).
- `plots` (created on run) — all chart images generated by the script.

## Dataset used
This uses the real **googleplaystore.csv** (10,841 apps, cleaned down to
9,659 valid rows) AND the real companion **googleplaystore_user_reviews.csv**
(64,295 reviews, 37,427 with usable text/sentiment after dropping apps with
no reviews collected). Sentiment labels (Positive/Negative/Neutral) come
straight from the dataset itself — no lexicon scoring needed.
