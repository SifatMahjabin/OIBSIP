# Sentiment Analysis

**Track:** Data Analytics — OIBSIP
**Deliverable folder:** `OIBSIP/DataAnalytics-L1-SentimentAnalysis/`

## Objective
Build a machine learning model that classifies the sentiment of text data (positive, negative, or neutral), providing insights into public opinion or customer feedback.
## Tech Stack
Python, pandas, scikit-learn, NLTK or TextBlob, matplotlib/seaborn, Jupyter Notebook


## What's in this folder
- `sentiment_analysis.py` — full pipeline: data loading, EDA, analysis, and charts, with inline comments explaining each decision (as required by the checklist's " written observation" items).
- `plots/` (created on run) — all chart images generated by the script.

## Dataset used
This uses the real Kaggle **Twitter Entity Sentiment Analysis** training set (`data/twitter_training.csv`, no header row — TweetID/Entity/Sentiment/Text). The original 4-class labels (Positive/Negative/Neutral/Irrelevant) are filtered down to 3 classes to match the task spec, with "Irrelevant" tweets dropped. A stratified 12,000-row sample is used by default for faster training (see `SAMPLE_SIZE` at the top of the script) — set it to `None` to train on the full ~74k rows.
