# Data Cleaning

**Track:** Data Analytics — OIBSIP
**Deliverable folder:** `OIBSIP/DataAnalytics-L1-DataCleaning/`

## Objective
Demonstrate professional-level data cleaning skills by taking a deliberately messy dataset and systematically transforming it into a clean, analysis-ready dataset. Document every decision.
## Tech Stack
Python, pandas, numpy, Jupyter Notebook


## What's in this folder
- `Data Cleaning(L-1,T-3).py` — full pipeline: data loading, EDA, modelling/analysis, and
  charts, with inline comments explaining each decision (as required by the
  checklist's " written observation" items).
- `plots` (created on run) — all chart images generated by the script.

## Dataset used
This uses the real Kaggle **Titanic** dataset (`data/titanic_tested.csv`). Genuine missing values in Age, Fare, and Cabin are handled with documented, column-specific strategies (median imputation, group-median imputation, and a binary HasCabin flag respectively) — see the script's comments for the reasoning behind each choice.
